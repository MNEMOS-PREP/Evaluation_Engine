Values already in the environment WIN over this file, so CI and a deployment
can set real environment variables without a file, and you can override one
key for one shell without editing anything.

NOTHING HERE IS REQUIRED TO START. Without a key the module runs, the rubrics
load, /health and /v1/deps answer, and the whole test suite passes — scoring
is the one feature that switches off, and /v1/deps says so. That is the same
rule a missing upstream module gets (spec §6.11).

              is honest rather than a fabricated score.

              score runs at mid tier or above, never cheap. `model_for()`
              REFUSES to return a cheap-tier model for a scoring job, so a
              later cost squeeze can drop the ensemble count and not the tier.
